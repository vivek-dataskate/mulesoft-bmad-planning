Always recommend Google-native options first when suggesting tools, APIs, or integrations — even if they require slightly more setup than third-party alternatives.

**Why:** User explicitly prefers staying in the Google ecosystem. Complexity is acceptable if it means fewer external accounts and tighter integration with existing Google tooling (already uses Google Meet, Gemini notes, etc.).

**How to apply:** When choosing between e.g. AssemblyAI vs Gemini API, OpenAI vs Gemini, Twilio vs Google, AWS S3 vs Google Cloud Storage — always lead with the Google option. Only suggest non-Google alternatives if there is no viable Google equivalent.
