How We See Your Business ▲

Agile Mind is a K-12 educational curriculum publisher that develops and licenses math and science programs (grades 6–12) including Intensified Algebra and Intensified Mathematics to school districts nationwide. Revenue comes from multi-year district agreements, and the critical production window — when print orders are placed and fulfilled — runs May through August. The core problem DataSkate is solving: two people spending hours on data entry that should happen automatically.

Internal — Architecture Pre-Decisions [DataSkate Only — Not Shown in PDF]

Pre-decision 1 — Auth Model
Salesforce = OAuth JWT (service account, jwt_bearer_token flow). QuickBooks = OAuth 2.0 Authorization Code with refresh token stored in CloudHub Secrets Manager — not in properties files.
Pre-decision 2 — QB Update Pattern (FK-017)
QBO API has no PUT or PATCH. All QB updates require POST with full object + current SyncToken. Must GET the object immediately before each POST to retrieve the current SyncToken. Stale SyncToken → 400 error. MuleSoft QBO connector handles 60-min token refresh automatically when configured with refresh token.
Pre-decision 3 — QB Version Gate (FK-020)
If Q4.1 answer is anything other than "QuickBooks Online (cloud)" — escalate immediately to Kailash. QB Desktop uses QBXML / Windows Web Connector — completely different architecture. Do not proceed with QBO connector scoping until version is confirmed.
Pre-decision 4 — Salesforce UC1 Trigger
Prefer Platform Event or Change Data Capture on Agreement__c rather than polling. Requires Chloe to confirm CDC is enabled in their Salesforce org (Q5.4). If CDC not available, fall back to scheduled polling with timestamp filter.
Pre-decision 5 — ISBN Lookup Table
Salesforce Custom Metadata Type is the recommended implementation for the state→ISBN mapping. Supports runtime update without code deployment. Kailash proposed this; Maria agreed. External ID field QB_InvoiceId__c must be created on Agreement__c before development begins.
Pre-decision 6 — Back-to-School Deployment Risk
Go-live target July 15, 2026. Back-to-school fulfillment peaks July–August. Recommend zero-downtime cutover at off-peak hours (early AM CT, Tuesday). Crystal and Maria must be on standby. If any slippage past July 1, recommend rescheduling to September to avoid production peak.
Pre-decision 7 — realmId Storage
QBO realmId must be stored in CloudHub Secrets Manager. Not in property files, not hardcoded in flow variables. Retrieve at flow startup. Refresh token must also be in Secrets Manager with update-after-refresh pattern (Intuit refresh tokens may rotate every 24–26 hours per Nov 2025 policy).
Pre-decision 8 — Inventory Committed/Available Logic
QB does not natively track "committed" quantity (orders placed but not yet fulfilled). Committed quantity must be derived from open Salesforce Agreement line items (not from QB). Available = QOH (from QB) − Committed (from SF open Agreements). This calculation lives in the integration layer or as a Salesforce formula field.
Pre-decision 9 — Google Sheets Auth Pattern
Use service-account auth (no user OAuth consent required for unattended flows). Holly must share the sheet with DataSkate's service account email one time. For large sheets (10K+ rows), use batch read with batchGet. If local Excel confirmed instead, switch to SFTP or OneDrive/SharePoint connector pattern.
Pre-decision 10 — QBO Rate Limits
500 req/min per realmId; max 10 concurrent connections; batch endpoint: 120 req/min. For UC2 and UC4 nightly batch flows: set maxConcurrency ≤ 5. If UC2 nightly run exceeds 60 minutes (large invoice count), implement 401-detect → refresh → retry wrapper around the QBO connector calls.
